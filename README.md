# ❤️ CardioCare: Heart Disease Risk Prediction (End-to-End Deep Learning App)

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg) ![Django](https://img.shields.io/badge/Django-4.0+-green.svg) ![Machine Learning](https://img.shields.io/badge/Sklearn-RandomForest-orange.svg)

### **📌 Project Overview**
CardioCare is a full-stack medical diagnostic tool designed to assist healthcare professionals in predicting heart disease risk. 

Unlike simple analysis notebooks, this project deploys a trained **Random Forest Classifier** into a robust **Django Web Application**. It features a user-friendly clinical dashboard that processes 13 distinct patient health metrics to generate real-time risk assessments.

---

### **🚀 Key Features**
* **Full-Stack Deployment:** Python (Django) backend integrated with a Machine Learning pipeline.
* **Clinical Dashboard:** Modern UI/UX designed for medical professionals.
* **Real-Time Inference:** Instant prediction (Sick/Healthy) based on user inputs.
* **Secure & Scalable:** Built on Django's secure framework, ready for hospital system integration.

---

### **🧠 The AI Engine**
The model was trained on the **Cleveland Heart Disease Dataset** (UCI Repository).
* **Algorithm:** Random Forest Classifier (Optimized for tabular medical data).
* **Accuracy:** ~88% on test data.
* **Preprocessing:** Handled missing values, normalized numerical inputs, and mapped categorical variables.

*(You can view the training process in the `Heart_Disease_Model.ipynb` file included in this repo.)*
